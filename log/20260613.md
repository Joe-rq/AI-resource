**主要技术内容**:

1. **四层标签链** `case_type → run_outcome → eval_finding → behavior_pattern`：业务到模式的连贯叙事
2. **数据栈**：trace_results.jsonl + run_summary.json + trace_bundles.zip + eval_labels.jsonl + 可选 trace_snapshot.sqlite
3. **三个核心公式**：
   - `trace_impact_score = severity_weight × (1 + findings_count) × (1 + loop_count / 4)`
   - `impact_score(k) = prevalence_share(k) × severity_weighted_prevalence(k)`
   - `lift = slice_pattern_share / overall_pattern_share`
   - `suspect_score = 0.4 × proximity + 0.3 × frequency + 0.2 × bridge + 0.1 × role`
4. **BERTopic 风格流程**：embedding (`e_i = f(d_i)`) → UMAP 降维 → HDBSCAN 聚类 → class-aware tf-idf 提取关键词 (`tf × log((1+N)/(1+df))`) → 解释为 behavior_pattern
5. **AgentTrace 风格诊断**：构造执行图 G=(V,E) → 选 focus event 锚点 → 反向回溯打 suspect_score
6. **关键阅读原则**：嫌疑榜首若是 `eval/review signal` 通常只是发现位置，不是根因——真正可操作的是周围业务事件
