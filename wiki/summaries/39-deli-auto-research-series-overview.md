# Deli AutoResearch 四论文系列总览与生产统计

**Source**: [Victor Chen / Deli Chen](https://victorchen96.github.io/auto_research/paper.html) · 2026-06-26

## Key takeaways

- Deli AutoResearch 项目目前已产出 **4 篇长篇综述**，覆盖自主研究 Agent、持续学习、长程决策与自博弈，总页数 265 页、BibTeX 条目 1,155 条。
- 四篇论文的最终自评分数分别为 8.5 / 8.5 / 8.5 / **8.6**/10；Paper #4 因 285B RL 实验 + 理论加固达到系列最高。
- 整个系列约消耗 **~44 小时 wall clock**、~2.55M 输出 token、~1,970 次工具调用、63+ 个子 Agent。
- 文献处理采用 4 阶段流水线：Recall → Score (LQS) → Classify (A/B/C/D) → Upgrade (arXiv → 已接收会场 via DBLP)。
- 项目还暴露了 LLM 生成综述的结构性风险：V12 主动降分正是因为外部引用核查发现不存在论文、作者错配、arXiv ID 错配三类错误。
