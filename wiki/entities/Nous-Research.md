# Nous Research

Nous Research 是硅谷 AI 研究实验室，开发了开源 Agent 框架 Hermes（GitHub 11万+星）。

## Key contributions / features

- **Hermes Agent**：对标 OpenClaw 的开源 Agent 框架，核心差异化在于长期记忆（非无状态）和自我进化（自动封装透明可查的技能文件）
- **社区热度**：GitHub 11万星说明开发者社区高度认可
- **医疗场景重点布局**：慢病管理、医生培训、科研辅助是主要落地方向
- **监管挑战**：自我进化特性难以通过 FDA/NMPA 医疗器械合规审查
