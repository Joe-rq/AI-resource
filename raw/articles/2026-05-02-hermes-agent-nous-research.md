# Hermes Agent / Nous Research

**Source**: 动脉网 · 2026-05-02 · https://mp.weixin.qq.com/s/wX7pMuK1rizqjmJqwNbGBQ

## Key takeaways

- Nous Research 是硅谷 AI 实验室，开发了开源 Agent 框架 **Hermes**（GitHub 11万+星），对标 OpenClaw
- 核心亮点：**长期记忆**（非无状态）+ **自我进化**（自动封装透明可查的技能文件）
- 医疗场景潜力：慢病管理、医生培训、科研辅助
- 挑战：自我进化特性难以通过现行医疗器械监管

## Core claims

Hermes 是 Nous Research 推出的开源智能体框架，社区热度达 11万星。其最大特点是区别于传统 AI 的无状态特性——具备**长期记忆能力**，能跨会话保持上下文连贯性。此外还有**自我进化**机制，能自动封装操作并生成透明可查的技能文件。医疗是重点落地场景，但自我进化特性在 FDA/NMPA 监管框架下仍是挑战。
